1. 원격 클라이언트가 payload JSON 생성
2. POST /api/v1/routing/jobs 로 전송
3. 서버가 job_id 반환
4. 클라이언트가 job_id로 상태 조회
5. 완료되면 result 조회


1. payload JSON 생성:
예시:
{
  "request_id": "Z-WEEKEND-20260516-001",
  "mode": "z_weekend",
  "city": "Atlanta, GA",
  "planning_date": "2026-05-16",
  "technicians": [],
  "jobs": [],
  "options": {
    "timezone_offset": "-04:00",
    "max_jobs_per_sm": 4
  }
}

2. 라우팅 서버 호출:
curl -X POST http://20.51.244.68:8055/api/v1/routing/jobs \
  -H "Content-Type: application/json" \
  -d @z_weekend_payload.json
응답:
{"job_id":"Z-WEEKEND-20260516-001_xxxxxxxx","status":"queued"}

3. 그 job_id로 상태 확인:
curl http://20.51.244.68:8055/api/v1/routing/jobs/<job_id>
응답:
{
  "job_id": "<job_id>",
  "status": "completed",
  "mode": "z_weekend",
  "city": "Atlanta, GA",
  "summary": {
    "total_jobs": 3,
    "assigned_jobs": 2,
    "unassigned_jobs": 1
  }
}

4. 완료 후 결과 조회:
curl http://20.51.244.68:8055/api/v1/routing/jobs/<job_id>/result
응답:
{
  "request_id": "Z-WEEKEND-20260516-001",
